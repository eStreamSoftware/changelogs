This release adds DuitNow payment mode for Bank of China and CPF and SHG contribution rates, updates Maybank2E-RC SOCSO payments, and fixes payroll, payslip, and bank file issues. (*250*)

<!-- truncate -->

## Features

- Added DuitNow payment mode to the **Bank of China** file format (#6416)
- Added **View CPF Contribution Rate** and **View SHG Contribution Rate** menu items

---

## Updates

- Updated **Maybank2E-RC Universal Payment** format to v7.4 for SOCSO payments (#6414)
- Updated **Mosque Building Fund** and **Mendaki Fund** captions to include their abbreviations

---

## Bug Fixes

- Fixed the Drive storage running low reminder appearing when Drive is not used
- Fixed "Leave type not found in employee leave group" error when updating payroll in Sync Cloud
- Fixed inability to process month-end payroll for the month following expiry of the registered license (#6423)
- Fixed incorrect sign for **Advance Deduct** on the Singapore **Payslip** (#6421)
- Fixed access violation in **Payroll Process** when calculating the unpaid leave amount for an unassigned calendar month (#6415)
- Fixed **Advance Deduct** on the Singapore **Paysheet** form not opening its details when clicked (#6422)
- Fixed the expected location not showing on the Sync Cloud Time Attendance map
- Fixed incorrect **Month of Contribution** format in **Hong Leong Connect Pro** EPF and SOCSO formats (#6418)
- Fixed access violation when double-clicking a row in the **Yearly Individual** main grid (#6419)
- Fixed the **Maybank2E-RC Universal Payment** file containing both IT and CN payment modes (#6413)
