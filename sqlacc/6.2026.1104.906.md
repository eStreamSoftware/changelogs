E-commerce and API 5 cents rounding updates, Stock Card Qty report field display, and various bug fixes. (*906*)

<!-- truncate -->

## Updates

- **E-Commerce**:
  - Adjusted the 5 cents rounding implementation for the e-commerce module.

- **API**:
  - Added support for the 5 cents rounding option on Sales Invoice, Cash Sales, Credit Note, and Debit Note (#8085).

- **Reports**:
  - Updated the Stock Card Qty report so master fields show or hide in the field chooser based on the selected Grouping. In the detail grid for transactions within the date range, the Agent and Area columns always display their values regardless of Grouping (#8058).

- **General**:
  - Revised document tab order (#8097).

## Bug Fixes

- **Maintain Customer/Supplier**:
  - Fixed Batch Edit for Classification in Maintain Customer and Maintain Supplier (#8108).

- **MyInvois (E-Invoice MY)**:
  - Fixed an issue where a field value could not be cleared when the e-Invoice size limit check is applied (#8109).
