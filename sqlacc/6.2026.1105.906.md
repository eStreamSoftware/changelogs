Fixed Assets Grand Total Depreciation, database upgrade, MyInvois, AR/AP Credit Note, and Year End bug fixes. (*906*)

## Bug Fixes

- **Fixed Assets**:
  - Fixed Grand Total Depreciation showing an incorrect amount.

- **General**:
  - Fixed an Assertion Failure error when upgrading a database from a version before 207 (#8118).
  - Fixed an error raised during Year End checking.

- **MyInvois (E-Invoice MY)**:
  - Fixed access violation when the MyInvois module is not available (#8117).

- **Sales / Purchase**:
  - Fixed AR/AP Credit Note so that, after filtering Outstanding Amount and knocking off several documents with the same amount, Save no longer returns the form to edit mode and no longer shows the Gain/Loss dialog for a local currency company (#8107).
